# 长江存储本体知识库

本库按源文件目录结构保存 PDF 与 Excel 的 Markdown 提取结果。每个文件保留同名路径，PDF 以页码分段，Excel 以工作表和行号分段。`_manifest.json` 记录源文件相对路径、SHA-256、页数及提取覆盖率。

## 当前覆盖率

- 共 37 份源文件：36 份 PDF、1 份 Excel。
- 24 份 PDF 提取到部分或全部文本；其中部分图表、旋转文字和扫描页仍可能遗漏。
- 12 份 PDF 无可提取文本层，共 750 页；对应 Markdown 只有页码和缺失标记，**不能作为内容证据**。另有 6 份 PDF 共 15 页未提取到文本。
- Excel 已按工作表和原始行号展开；公式按公式文本保存。

请先读取 `_manifest.json` 的 `low_text_pages` 与 `extracted_chars` 字段。引用证据时使用 Markdown 文件路径及页码/行号；无法读取的页不得推断内容。对于关键数值，回看原始文档核对表格、图注、单位和日期。
